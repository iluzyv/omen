# OMEN ✶

A zero-build static site for **OMEN — Embrace Mystery**.

## Run locally
Open `index.html`, or run:
`python3 -m http.server 3000`

## Deploy
GitHub Pages, Vercel, Netlify, or any static host.

## Before launch
Replace the X link in `index.html` and replace `COMING SOON` in the artifact section with the contract address.
